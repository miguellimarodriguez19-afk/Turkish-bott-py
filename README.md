# Turkish Bot - Python Edition 🐍

Bot Discord em Python com comando `!send_components` que exibe uma galeria de mídia com separadores e texto formatado!

## 📋 Comandos

- `!send_components` - Envia os componentes com a imagem e texto
- `!ping` - Responde com Pong! 🏓

## 🚀 Setup

1. Clone o repositório
2. Instale as dependências:
   ```bash
   pip install -r requirements.txt
   ```

3. Crie um arquivo `.env` com seu token:
   ```
   DISCORD_TOKEN=seu_token_aqui
   ```

4. Execute o bot:
   ```bash
   python main.py
   ```

## 📦 Dependências

- discord.py
- python-dotenv
